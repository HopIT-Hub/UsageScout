# Contributing to UsageScout

Thanks for opening issues and helping improve UsageScout.

## Issues

Issues are welcome from anyone.

## Pull Requests

Code contributions are accepted only if the contributor agrees to `CLA.md`.

By opening a PR, you confirm:
- you have the right to submit the contribution
- you agree your contribution is licensed to HopIT under `CLA.md`
- you understand HopIT may use and commercialize contributions

If you do not agree with `CLA.md`, please do not submit code PRs.

## Attribution and License Terms

All contributions are subject to:
- `LICENSE`
- `LICENSE-ADDITIONAL-TERMS.md`

Forks and public variants must preserve required attribution in README and user-accessible UI settings/about areas, per `LICENSE-ADDITIONAL-TERMS.md`.
